# Créditos de las fotos

Todas tienen licencia libre (Creative Commons BY-SA o CC0). Para usarlas en Autobahn se recortaron a
proporción 3:2 y se redujeron a 800 × 533 píxeles. La ficha de cada auto muestra el autor, la licencia y
el enlace a la página original de la foto.
